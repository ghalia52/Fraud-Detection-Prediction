# Fraud Detection Machine Learning Project

This project focuses on building and evaluating machine learning models for detecting fraudulent transactions. It includes data preprocessing, resampling, model training, performance evaluation, and comparison across multiple classifiers.

## 📌 Project Overview

Fraud detection is a highly imbalanced classification problem. This project uses techniques such as:

* **Data scaling**
* **SMOTE resampling**
* **Model comparison**
* **ROC-AUC evaluation**
* **Precision, recall, and F1-score metrics**

## 🚀 Features

* End-to-end ML workflow
* Multiple models tested:

  * Logistic Regression
  * Random Forest
  * Gradient Boosting
* Clean evaluation pipeline
* Notebook with visualizations and results

## 📊 Results

Each model is evaluated using:

* ROC-AUC score
* Classification report
* Confusion matrix

The project highlights the strengths of ensemble models for fraud detection.
